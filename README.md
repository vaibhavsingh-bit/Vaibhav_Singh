# Vaibhav Singh - Personal Portfolio

A simple, attractive, responsive personal portfolio made only with HTML5 and CSS3.

## Files
- `index.html` - portfolio structure and content
- `style.css` - styling, Flexbox/Grid, hover effects, animation and media queries
- `images/profile-placeholder.svg` - temporary profile image

## Before GitHub submission
Replace `images/profile-placeholder.svg` with your actual profile photograph.
If you use a JPG/PNG, change the image filename in `index.html` accordingly.

## Run
Open `index.html` in any web browser.

## GitHub
Recommended repository name: `vaibhav-singh-portfolio`
